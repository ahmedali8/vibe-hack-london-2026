# Validation Report

Scale 0–100, 100 = healthiest. Generated by `build/build_anchor.py` and `build/build_food.py`.

## Anchor: `pcos_scored.csv` (n = 541)

The score is computed from clinical features via the literature-grounded rubric and is **never
fit to the label**. We then test whether it separates the held-out `PCOS_label`.

| Metric | Value |
|---|---|
| PCOS-positive / negative | 177 / 364 |
| Mean score, PCOS+ | **59.3** |
| Mean score, PCOS− | **82.2** |
| Median score, PCOS+ / PCOS− | 58.1 / 84.4 |
| **AUC (score separates label)** | **0.914** |

Direction is correct (PCOS+ score lower) and discrimination is strong (AUC 0.91) for an
unsupervised, transparent rubric — i.e. the clinical literature alone, without training on the
diagnosis, ranks patients well.

### Sub-score means by label (every dimension moves the right way)

| Sub-score | PCOS− | PCOS+ | gap |
|---|---:|---:|---:|
| Hyperandrogenism | 77.3 | 39.1 | 38.2 |
| Cycle / ovulatory | 87.0 | 55.0 | 32.0 |
| Imaging / PCOM | 97.4 | 72.3 | 25.1 |
| Metabolic | 74.9 | 63.9 | 11.0 |
| Hormonal | 82.2 | 76.2 | 6.0 |
| Lifestyle | 63.4 | 51.2 | 12.2 |

The three Rotterdam diagnostic pillars (hyperandrogenism, cycle, imaging) drive the largest
separation — as expected. Metabolic/hormonal gaps are smaller, consistent with PCOS phenotype
heterogeneity (normoandrogenic/lean phenotypes exist).

## Food reference: `food_scored.csv` (n = 13,694)

| Metric | Value |
|---|---|
| Foods scored | 13,694 (Foundation 469, SR-Legacy 7,793, Survey/FNDDS 5,432) |
| With nutrient data | 13,612 (~99.4%); ~82 placeholders sit at base 50 |
| Mean diet score | 49.3 |
| Levels | Moderate 10,221 · Poor 1,610 · Good 1,578 · Very Poor 221 · Excellent 64 |

Face validity — highest: ground mustard seed, roasted soybeans, peanut flour, raw almonds,
flaxseed (high fiber/protein/unsaturated fat). Lowest: flavored creamer, frosted cookies,
candy sprinkles, sweetened instant coffee (sugar/saturated fat dominant). Correct direction.

## Limitations
- Research / app-prototype only; **not diagnostic**. Single 541-subject cohort (Kerala fertility clinic).
- AMH thresholds are age/assay-sensitive; rubric uses age-specific cutoffs but a fixed assay assumption.
- Food score is a transparent heuristic, not a clinically validated diet index; lacks glycemic
  index and micronutrients (inositol, magnesium) not present in the source tables.
- No cross-population joins: diet/food scores are independent reference layers, not patient-linked.
